feat(memory): read the journal from Walrus instead of an audit table

Drop memory_writes entirely: it duplicated what the relayer already
returns and made Walrus look like a cache of Postgres. remember() now
returns the blob id as the receipt and writes nothing locally.

/memory shows decoded memory text, which needed listMemories() metadata
joined to a neutral recall() — the only call that returns plaintext.

Add /journals: a session-free, read-only view reconstructed from the
relayer alone. server/scoring/reconstruct.ts joins pick_commit to
outcome on the ids inside the memory text, so credibility and bias are
derived without SQL. pnpm verify:reconstruct proves the result matches
Postgres for every analyst (0 mismatches).
